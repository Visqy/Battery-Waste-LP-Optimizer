# User Guide

## 1. Purpose

This guide explains how to use the NMC Battery Recycling Policy Decision Support Tool.

The software helps users evaluate supply allocation, facility capacity, economic outcome, and policy-relevant indicators for NMC electric vehicle battery recycling on Java Island, Indonesia.

The software does not make policy decisions automatically. It provides transparent scenario-based evidence to support further analysis.

## 2. Intended Users

This guide is written for:

- Policy stakeholders
- Public sector planners
- Recycling infrastructure analysts
- Researchers
- Technical staff preparing input data
- Reviewers evaluating the software workflow

## 3. Main Workflow

The recommended workflow is:

```text
Prepare input data
Run validation
Run optimization
Review executive decision summary
Review technical results
Export results
Export current configuration if needed
```

## 4. Starting the Application

Run the application from the project root directory:

```bash
python -m shiny run app.py --reload
```

Open:

```text
http://127.0.0.1:8000
```

## 5. Home Page

The Home page explains the decision context, model scope, locked model, stakeholder workflow, key outputs, and data units.

Use this page to understand what the software can and cannot answer.

The main decision questions are:

- Can the current recycling network absorb available NMC battery waste supply?
- Does the scenario generate a positive net economic benefit?
- Is there unused supply?
- Is there unused facility capacity?
- Which facilities may become bottlenecks?
- What follow-up analysis should be considered?

## 6. Template Page

Use the Template page to download the Excel input template.

The input workbook must include:

```text
collection_centers
recycling_facilities
transport_costs
```

Optional sheets may include:

```text
metadata
scenario_notes
```

The template is useful when preparing a new scenario outside the GUI.

## 7. Upload Data Page

Use the Upload Data page to upload a completed Excel input file.

After upload, the application replaces the active dataset with the uploaded data.

A valid upload must contain:

- Collection center data
- Recycling facility data
- Complete transport cost routes
- Non-negative numeric values
- Matching IDs across sheets

If upload fails, check the error message and revise the Excel file.

## 8. Parameter Editor Page

Use the Parameter Editor page to edit the active scenario directly in the GUI.

Editable values include:

- Collection center name
- Collection center province
- Supply in kg/year
- Recycling facility name
- Recycling facility province
- Capacity in kg/year
- Processing cost in Rp/kg
- Recovery revenue in Rp/kg
- Route transport cost in Rp/kg

The model formulation cannot be edited. The objective function, constraints, solver logic, and model type remain locked.

After editing parameters, run validation again.

## 9. Validation Page

Use the Validation page before optimization.

Validation checks:

- Required sheets
- Required columns
- Missing values
- Duplicate IDs
- Negative values
- Complete route matrix
- Total supply
- Total capacity
- Number of routes

Optimization should not be run if validation fails.

Warnings do not block optimization, but users should review them before interpreting the result.

## 10. Optimization Page

Use the Optimization page to run the locked LP model.

The model uses PuLP and the CBC solver.

The optimization step produces:

- Solver status
- Objective value
- Runtime
- Route allocation
- Supply slack
- Capacity slack
- Shadow price when available

If the solver status is not Optimal, do not use the result as a policy conclusion.

## 11. Results Page

The Results page is divided into decision-oriented and technical sections.

### Executive Decision Summary

This section summarizes the scenario for stakeholders.

It includes:

- Economic status
- Supply status
- Capacity status
- Policy priority

### Policy Insight

This section translates optimization results into a policy-relevant interpretation.

It explains:

- Whether the scenario produces a positive net benefit or net cost
- Whether available supply is fully absorbed
- Whether capacity pressure or bottlenecks exist
- What follow-up analysis should be considered

The policy insight is generated by deterministic rules. It is not an AI-generated recommendation.

### Key Indicators

This section shows:

- Estimated net benefit or estimated net cost
- Supply absorption percentage
- System capacity utilization percentage
- Highest facility utilization percentage

### Technical Objective

This section shows the LP objective value.

A negative objective value does not indicate a loss. It indicates a positive net benefit when recovered material revenue exceeds transportation and processing costs.

### Allocation Matrix

This table shows how much NMC battery waste is allocated from each collection center to each recycling facility.

### Route Allocation Detail

This table shows route-level allocation and economic coefficients.

Important fields include:

- Transport cost
- Processing cost
- Recovery revenue
- Net cost coefficient
- Allocated volume
- Route net benefit

### Charts

The charts show:

- Facility utilization
- Supply usage by collection center

### Constraint Analysis

This table shows:

- Supply constraints
- Capacity constraints
- Slack values
- Shadow prices
- Binding status

A binding constraint has no slack and may indicate a limiting factor in the network.

## 12. Interpreting Main Indicators

### Economic Status

Positive Net Benefit means recovered material revenue exceeds transportation and processing costs.

Net Economic Cost means transportation and processing costs exceed recovered material revenue.

Break Even means total cost and recovered material revenue are balanced.

### Supply Status

Full Supply Absorption means the model allocates nearly all available supply.

Partial Supply Absorption means some supply remains unallocated.

### Capacity Status

Capacity Reserve Available means the system still has unused facility capacity.

High Capacity Pressure means at least one facility is heavily utilized.

Capacity Bottleneck means at least one facility reaches its capacity limit.

### Policy Priority

Policy Priority summarizes what should receive attention in the current scenario.

Examples include:

- Maintain collection reliability and active facility operation
- Monitor facility utilization and prepare capacity contingency options
- Assess capacity expansion or additional processing partnership
- Review cost structure and recovered material revenue assumptions

## 13. Export Results

Use Export Results to Excel to download the optimization result workbook.

Expected sheets:

```text
policy_summary
summary
allocation_matrix
route_allocation
facility_utilization
supply_usage
constraints
interpretation
```

The policy_summary sheet is intended for non-technical review.

The technical sheets are intended for detailed verification and further analysis.

## 14. Export Current Configuration

Use Export Current Configuration to download the active input scenario.

Expected sheets:

```text
metadata
collection_centers
recycling_facilities
transport_costs
scenario_notes
```

This file can be uploaded again later as a reusable scenario.

## 15. Recommended Use for Policy Stakeholders

For policy review, use this order:

1. Read Economic Status.
2. Read Supply Status.
3. Read Capacity Status.
4. Read Policy Priority.
5. Read Policy Insight.
6. Check whether unused supply or unused capacity exists.
7. Review capacity bottlenecks.
8. Export policy_summary for discussion.
9. Use technical tables only when detailed verification is required.

## 16. Important Limitations

1. The model is deterministic.
2. The model uses one annual planning period.
3. All recycling facilities are assumed active.
4. Facility location decisions are not optimized.
5. Environmental impact is not included.
6. Material recovery efficiency is not optimized as a separate objective.
7. Uncertainty is not modeled.
8. The policy insight is rule-based.
9. The software supports decision analysis, not automatic policy prescription.

## 17. Troubleshooting

### Upload fails

Check that the workbook contains all required sheets and columns.

### Validation fails

Open the Validation tab and review all error messages.

### Optimization does not run

Run validation first and fix all errors.

### Objective value is negative

This can be valid. A negative objective value means the net cost is negative, which indicates a positive net economic benefit.

### Export file cannot be opened

Close any currently open version of the exported Excel file and export again.

## 18. Suggested Scenario Analysis

Users can test scenarios such as:

- Higher future battery waste supply
- Lower or higher recovered material revenue
- Higher transport cost
- Facility capacity expansion
- Alternative route cost assumptions
- Reduced facility capacity
- New collection center scenarios

Each scenario should be validated and exported separately.
