# Examples

This folder stores example input and output files for the NMC Battery Recycling Allocation Optimizer.

Recommended files:

```text
sample_input.xlsx
sample_output.xlsx
sample_current_configuration.xlsx
```

## sample_input.xlsx

This file should follow the same structure as the application input template.

Required sheets:

```text
collection_centers
recycling_facilities
transport_costs
```

Optional sheets:

```text
metadata
scenario_notes
```

This file can be generated by downloading the template from the application and filling in the required values.

## sample_output.xlsx

This file should be generated from the Results tab by clicking:

```text
Export Results to Excel (.xlsx)
```

Expected sheets:

```text
diagnostics_summary
summary
allocation_matrix
route_allocation
facility_utilization
supply_usage
constraints
interpretation
```

## sample_current_configuration.xlsx

This file should be generated from the Results tab by clicking:

```text
Export Current Configuration (.xlsx)
```

Expected sheets:

```text
metadata
collection_centers
recycling_facilities
transport_costs
scenario_notes
```

The current configuration file can be uploaded again as an input scenario.
